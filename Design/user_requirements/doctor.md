# User Requirements — Doctor

## What can they do
1. Can create/update/cancel a dental treatment plan for patient
2. Can add instructions and notes for the next procedure of the patient
3. Can do everything that assistant can do
4. Can create proposal of treatment plan for special procedure (such as implant or orthondontic or anything is marked as special procedure)
5. Can proposal special discount (need approval) for a specific treatment plan
6. Can manage procedure's set of instructions
7. Can page other assistant staff / manager for work's notification
